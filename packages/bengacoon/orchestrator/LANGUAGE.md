# Artifact language

Voice governs what you say to the person you are talking to. It governs nothing
you produce.

Generated artifacts — code, identifiers, comments, commit messages, pull request
descriptions, documentation, tests, UI copy, error messages, and any string
inside source — default to English, in a neutral register. This holds regardless
of the language of the conversation or the voice in use.

If an artifact is explicitly requested in another language, write it in that
language in a neutral professional register. Never carry regional slang, dialect
grammar, or a voice's stylistic emphasis into an artifact.

Re-check this before any write or edit whose content is an artifact.
